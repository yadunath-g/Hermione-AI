# 📜 Project Hermione: The Pensieve v1.5
**Affective Computing Interface & Persistent Context Vault**

Developed as a demonstration of **Stateful AI Orchestration** and **Custom Terminal UI Design** during my BCA studies.

## 🛠️ Technical Highlights
* **LLM Engine:** Llama 3.1-8b via Groq Cloud API.
* **Aura Engine:** Real-time NLP sentiment mapping to 24-bit TrueColor ANSI output.
* **Contextual Persistence:** Implementation of a JSON-based long-term memory vault.
* **Temporal Awareness:** Dynamic environment injection (Time/User State) for adaptive greetings.

## 🚀 Getting Started
1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Add your **Groq API Key** to the configuration block in `main.py`.
4. Run the application: `python3 main.py`
